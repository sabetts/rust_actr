run the build-actr-distro.sh script with three parameters to send all of the
created files to act-r.psy.cmu.edu/actr7.x/next:

./build-actr-distro 7.x send send

Then run the build-actr-container-distro with the version and send:

./build-actr-container-distro 7.x send

Notes:

Sending the container however doesn't really do anything since the container
has cached the downloaded file so it doesn't actually update currently 
without me "touching" the Dockerfile to invalidate that.

Follow up to that. Don't need to touch the Dockerfile, but do need to
rebuild it.  Can be done using play-with-docker:

git clone https://github.com/db30/act-r-container
cd act-r-container
docker build --no-cache=true -t db30/act-r-container .
docker login
docker push db30/act-r-container

That doesn't change the mybinder cache however which will require that
something be done, like change the Dockerfile (probably something else
can be done but not sure at this point).

Also, it seems like libreoffice on my Linux box seems to sometimes lose the
update macro after it's been added so probably want to open it first and 
paste it in again to be safe.
