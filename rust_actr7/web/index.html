What is ACT-R?

      
A quick orientation to the architecture and this page.

    

    
  

  

    
ACT-R is a theory of human cognition expressed as a programming language. A model describes what a person knows, what they can perceive and do, and the rules that tie it together. Running the model produces a timestamped trace of every decision and memory retrieval.
