# Regression specs

This directory is no longer the driver corpus. Every ref has a Rust driver in
`tests/cases/<ident>.rs`; only data-heavy experiment specs are still read at
test time:

- **Data-heavy experiments** — cases whose Rust file carries a
  `//! spec: fixtures/regression/specs/<name>.spec` header (Monte-Carlo
  drivers with tens of thousands of runs).

Everything else, including all event-hook drivers, was translated into its
per-case file and deleted. If a spec is regenerated by `../regen-specs.sh`,
delete the ones no longer referenced by a `//! spec:` header and keep this
directory to that kind.
