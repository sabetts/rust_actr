# Regression specs

This directory is no longer the driver corpus. Every ref has a Rust driver in
`tests/cases/<ident>.rs`; only these specs are still read at test time:

- **Event-hook drivers** — the `.spec` named in the second column of
  `../hook-cases.txt`. The hook IR in `tests/hooks/` needs the driver's
  models/seed/steps/device.
- **Data-heavy experiments** — cases whose Rust file carries a
  `//! spec: fixtures/regression/specs/<name>.spec` header (Monte-Carlo
  drivers with tens of thousands of runs).

Everything else was translated into its per-case file and deleted. If a spec
is regenerated by `../regen-specs.sh`, delete the ones no longer referenced by
`../hook-cases.txt` or a `//! spec:` header, and keep this directory to the
same two kinds.
